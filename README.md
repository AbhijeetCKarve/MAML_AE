# MAML_AE
MAML with LSTM autoencoders for few-shot anomaly detection in IIoT. Cross-benchmark study on SMAP, SWaT, WADI. Corrects MAML implementation flaw. Finding: meta-learning no edge within plant (AUROC 0.579≈0.580). Helps only cross-plant transfer. Task-diversity diagnostic included. Five-seed evaluation. Targets Neurocomputing.
